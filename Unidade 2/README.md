# 📊 Módulo 2 — Excel para Análise de Dados
### 🛤️ Análise de Dados — Data Analytics com Dados Abertos da PRF
![Microsoft Excel](https://img.shields.io/badge/Microsoft_Excel-217346?style=for-the-badge&logo=microsoft-excel&logoColor=white)

## 🎯 Objetivo

Explorar inicialmente a base de acidentes da Polícia Rodoviária Federal (PRF) de 2025, utilizando recursos de planilhas para organizar, resumir e visualizar os dados.

A atividade tem como foco a utilização de **filtros, tabelas dinâmicas e gráficos**, construindo as primeiras evidências sobre os acidentes fatais nas rodovias federais brasileiras.

---

## 📦 Produto

**Planilha Exploratória Inicial**

A análise foi desenvolvida originalmente no **Google Sheets** e posteriormente exportada para o formato `.xlsx` para disponibilização no GitHub.

### 📐 Estrutura da Planilha

A planilha está organizada nas seguintes abas para garantir navegabilidade e clareza:

| Aba | Descrição |
| :--- | :--- |
| **🗃️ Dados** | Base de acidentes utilizada na análise (`tb_acidentes_prf`) |
| **📘 Dicionário** | Descrição e identificação das variáveis presentes na base |
| **🧮 Tabelas dinâmicas** | Agregações e cruzamentos utilizados para explorar os dados |
| **📈 Gráficos** | Visualizações construídas a partir das análises |
| **📝 Observações** | Principais observações e interpretações obtidas durante a exploração |
| **📌 Visão Geral** | Panorama geral dos principais resultados encontrados |

---

## 🛠️ Recursos Utilizados

Para transformar os dados brutos em informações estruturadas, foram aplicadas as seguintes técnicas:
* **Filtros Avançados:** Isolamento de cenários críticos e segmentação de variáveis.
* **Tabelas Dinâmicas:** Cruzamento de dados e sumarização estatística.
* **Gráficos Interativos:** Construção de recursos visuais para suporte à tomada de decisão.
* **Data Prep Prévia:** Organização, higienização e exploração inicial de grandes volumes de dados.
* **Análise Crítica:** Interpretação dos resultados e identificação de padrões de causa raiz.
* **Visão Executiva:** Consolidação de indicadores-chave em um panorama de visão geral.

---

## 💾 Base de Dados

A análise utiliza dados abertos da **Polícia Rodoviária Federal (PRF)** referentes aos acidentes registrados in 2025.

A base pertence ao conjunto de dados **DATATRAN**.
